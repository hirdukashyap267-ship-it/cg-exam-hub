Cyber Security Complete Notes in Hindi

Cyber Security के सभी महत्वपूर्ण टॉपिक आसान हिंदी भाषा में। Hacking, Malware, Phishing, Firewall, Encryption, Cyber Crime और Online Safety की परीक्षा उपयोगी जानकारी।

25 Important Topics Exam Special Notes
Topic 01

🛡️ Cyber Security क्या है?

Cyber Security एक ऐसी प्रक्रिया है जिसमें Computers, Networks, Applications और Digital Data को Unauthorized Access, Cyber Attacks और नुकसान से सुरक्षित रखा जाता है।

मुख्य उद्देश्य

  • Data को सुरक्षित रखना।
  • Unauthorized Access रोकना।
  • Online Fraud से बचाव करना।
  • Network और Systems की सुरक्षा करना।
  • Data की Privacy और Availability बनाए रखना।
🧠 Trick: Cyber Security = Digital दुनिया की सुरक्षा।
🎯 Exam Point: Cyber Security का उद्देश्य Digital Systems और Data को सुरक्षित रखना है।
Topic 02

🔐 CIA Triad

CIA Triad Cyber Security के तीन मुख्य सिद्धांतों का समूह है।

  • Confidentiality: जानकारी केवल अधिकृत व्यक्ति तक पहुँचे।
  • Integrity: Data सही और बिना अनधिकृत बदलाव के रहे।
  • Availability: जरूरत पड़ने पर Data और Services उपलब्ध रहें।
🧠 Trick: C = गोपनीयता, I = अखंडता, A = उपलब्धता।
⭐ Important: CIA Triad Information Security का मूल आधार है।
Topic 03

💻 Cyber Attack क्या है?

Cyber Attack एक ऐसा प्रयास है जिसमें किसी Computer, Network, Website या Digital Account को नुकसान पहुँचाने अथवा जानकारी चुराने की कोशिश की जाती है।

मुख्य उद्देश्य

  • Data चोरी करना।
  • Website या Service बंद करना।
  • Account पर Unauthorized Access प्राप्त करना।
  • पैसे की धोखाधड़ी करना।
  • Data में अनधिकृत बदलाव करना।
🧠 Trick: Cyber Attack = Digital System पर हमला।
Topic 04

🎭 Hacking क्या है?

Hacking का अर्थ Computer System, Network या Software की कमजोरियों को समझकर उसमें प्रवेश करना या उसकी कार्यप्रणाली में बदलाव करना हो सकता है। बिना अनुमति किया गया प्रवेश गैरकानूनी हो सकता है।

Hacker के प्रकार

  • White Hat Hacker: अनुमति लेकर Security Testing करता है।
  • Black Hat Hacker: दुर्भावनापूर्ण या गैरकानूनी उद्देश्य से हमला करता है।
  • Grey Hat Hacker: बिना अनुमति कमजोरी खोज सकता है, लेकिन उसका उद्देश्य हमेशा नुकसान पहुँचाना नहीं होता।
🧠 Trick: White = Ethical, Black = Malicious, Grey = बीच की स्थिति।
Topic 05

🦠 Malware क्या है?

Malware का पूरा नाम Malicious Software है। यह ऐसा Software है जिसे Computer, Network या Data को नुकसान पहुँचाने अथवा अनधिकृत गतिविधि करने के लिए बनाया जाता है।

Malware के प्रकार

  • Virus
  • Worm
  • Trojan Horse
  • Ransomware
  • Spyware
  • Adware
  • Rootkit
  • Keylogger
🧠 Trick: Malware = नुकसान पहुँचाने वाला Software।
Topic 06

🧬 Computer Virus

Computer Virus एक प्रकार का Malware है जो किसी File या Program से जुड़कर फैल सकता है। संक्रमित File चलाने पर यह सक्रिय हो सकता है।

प्रभाव

  • Files को नुकसान पहुँचा सकता है।
  • Computer की Performance धीमी कर सकता है।
  • Data को खराब कर सकता है।
  • अन्य Files को संक्रमित कर सकता है।
⭐ Important: Virus सामान्यतः किसी Host File या Program से जुड़ा होता है।
Topic 07

🐛 Worm क्या है?

Worm एक प्रकार का Malware है जो स्वयं की Copies बनाकर Network के माध्यम से फैल सकता है। इसे फैलने के लिए सामान्यतः किसी Host File की जरूरत नहीं होती।

VirusWorm
आमतौर पर Host File से जुड़ता है।स्वयं की Copies बनाकर फैल सकता है।
संक्रमित File चलने पर सक्रिय हो सकता है।Network के माध्यम से तेजी से फैल सकता है।
🧠 Trick: Worm = खुद फैलने वाला Malware।
Topic 08

🎁 Trojan Horse

Trojan Horse ऐसा Malware है जो उपयोगी या सामान्य Software जैसा दिखाई दे सकता है, लेकिन अंदर से नुकसानदायक गतिविधि करता है।

  • नकली Software के रूप में आ सकता है।
  • अनधिकृत Access दे सकता है।
  • Data चोरी करने में मदद कर सकता है।
  • अन्य Malware को Install कर सकता है।
🧠 Trick: Trojan = बाहर से अच्छा, अंदर से खतरनाक।
Topic 09

🔒 Ransomware

Ransomware एक प्रकार का Malware है जो Data को Lock या Encrypt कर सकता है और उसे वापस देने के बदले फिरौती माँग सकता है।

बचाव

  • नियमित Backup रखें।
  • संदिग्ध Email Attachment न खोलें।
  • Software Update रखें।
  • अनजान Links पर Click न करें।
⭐ Exam Point: Ransomware का संबंध फिरौती माँगने से है।
Topic 10

🕵️ Spyware और Keylogger

Spyware: उपयोगकर्ता की जानकारी या गतिविधियों को गुप्त रूप से एकत्र करने वाला Software.

Keylogger: Keyboard पर टाइप की गई जानकारी Record करने वाला Tool या Malware.

  • Password चोरी होने का खतरा।
  • Personal Information की चोरी।
  • Banking Details के दुरुपयोग का खतरा।
🧠 Trick: Spyware = जासूसी, Keylogger = Keyboard की गतिविधि Record करना।
Topic 11

🎣 Phishing Attack

Phishing एक Cyber Fraud है जिसमें नकली Email, SMS, Message या Website के माध्यम से Password, OTP और Banking Details जैसी जानकारी चुराने का प्रयास किया जाता है।

Phishing के प्रकार

  • Email Phishing: नकली Email भेजना।
  • Spear Phishing: किसी विशेष व्यक्ति या संस्था को Target करना।
  • Smishing: SMS के माध्यम से धोखाधड़ी।
  • Vishing: Phone Call या Voice के माध्यम से धोखाधड़ी।
  • Clone Phishing: असली Message की नकल करके नकली Link या Attachment भेजना।
🧠 Trick: Phishing = नकली पहचान से जानकारी चुराना।
Topic 12

📱 Social Engineering

Social Engineering में लोगों को धोखे या मनोवैज्ञानिक तरीकों से गोपनीय जानकारी देने अथवा कोई गलत कार्य करने के लिए प्रेरित किया जाता है।

उदाहरण

  • नकली बैंक अधिकारी बनकर Call करना।
  • OTP माँगना।
  • नकली Customer Care बनना।
  • फर्जी नौकरी या पुरस्कार का लालच देना।
  • नकली Login Page भेजना।
⭐ Important: Social Engineering में इंसान की गलती या विश्वास का फायदा उठाया जाता है।
Topic 13

💥 DoS और DDoS Attack

DoS: Denial of Service Attack में किसी Service को अधिक Requests या अन्य तरीकों से अनुपलब्ध करने का प्रयास किया जाता है।

DDoS: Distributed Denial of Service में कई अलग-अलग Systems से हमला किया जाता है।

DoSDDoS
एक या सीमित स्रोत से हमला हो सकता है।कई स्रोतों से हमला किया जाता है।
Single Source हो सकता है।Distributed Sources होते हैं।
🧠 Trick: DDoS = कई Devices से Service पर हमला।
Topic 14

🔑 Password Security

Password किसी User Account या System तक पहुँच को नियंत्रित करने का एक तरीका है।

मजबूत Password की विशेषताएँ

  • लंबा और Unique Password रखें।
  • अलग-अलग Accounts में अलग Password रखें।
  • नाम और जन्मतिथि जैसे आसान Password न रखें।
  • Password Manager का उपयोग कर सकते हैं।
  • Password किसी के साथ साझा न करें।
🧠 Trick: Strong Password = लंबा + Unique + कठिन अनुमान।
Topic 15

📲 Two-Factor Authentication (2FA)

2FA में Login के लिए Password के अलावा एक अतिरिक्त Verification Step की आवश्यकता होती है।

उदाहरण

  • Password + Authenticator App Code.
  • Password + Security Key.
  • Password + अन्य अतिरिक्त Verification Method.
⭐ Important: 2FA Account Security को मजबूत करता है।
Topic 16

🔐 Encryption और Decryption

Encryption: सामान्य Data को सुरक्षित Coded Form में बदलना।

Decryption: Coded Data को फिर से पढ़ने योग्य रूप में बदलना।

Encryption के प्रकार

  • Symmetric Encryption: Encryption और Decryption के लिए एक ही Secret Key का उपयोग होता है।
  • Asymmetric Encryption: Public Key और Private Key की जोड़ी का उपयोग होता है।
🧠 Trick: Encryption = छिपाना, Decryption = वापस पढ़ना।
Topic 17

🧱 Firewall क्या है?

Firewall एक Security System है जो निर्धारित नियमों के आधार पर आने-जाने वाले Network Traffic को Allow या Block करता है।

Firewall के प्रकार

  • Packet Filtering Firewall.
  • Stateful Inspection Firewall.
  • Proxy Firewall.
  • Next-Generation Firewall.
🧠 Trick: Firewall = Network का Security Guard.
Topic 18

🛡️ Antivirus क्या है?

Antivirus एक Security Software है जो Computer में Virus और अन्य Malware को पहचानने, रोकने तथा हटाने में सहायता करता है।

उदाहरण

  • Microsoft Defender.
  • Quick Heal.
  • Avast.
  • Bitdefender.
  • ESET.
⭐ Important: Antivirus को नियमित रूप से Update रखना चाहिए।
Topic 19

🌐 Network Security

Network Security का उद्देश्य Network और उससे जुड़े Devices को Unauthorized Access, Misuse और Cyber Attacks से सुरक्षित रखना है।

मुख्य उपाय

  • Firewall का उपयोग।
  • Secure Wi-Fi Password.
  • Network Monitoring.
  • Encryption.
  • Access Control.
  • Regular Updates.
🧠 Trick: Network Security = Network की सुरक्षा।
Topic 20

📡 VPN क्या है?

VPN का पूरा नाम Virtual Private Network है। यह Network के माध्यम से सुरक्षित Connection बनाने में सहायता करता है। VPN सामान्यतः Traffic को Encrypt करता है और उपयोगकर्ता के IP Address को अन्य Address के रूप में दिखा सकता है।

VPN के उपयोग

  • Public Wi-Fi पर सुरक्षा बढ़ाना।
  • Remote Access देना।
  • Network Traffic को Encrypt करना।
  • Private Network से सुरक्षित Connection बनाना।
🧠 Trick: VPN = Virtual Private Network.
Topic 21

📜 Digital Signature

Digital Signature एक Cryptographic तकनीक है जो Digital Message या Document की Authenticity और Integrity जाँचने में सहायता करती है।

  • Sender की पहचान की पुष्टि में मदद।
  • Document में बदलाव का पता लगाने में मदद।
  • Public Key Cryptography पर आधारित।
⭐ Important: Digital Signature, सामान्य Digital Image या स्कैन किए गए हस्ताक्षर से अलग होता है।
Topic 22

🚨 Cyber Crime क्या है?

Cyber Crime वह अपराध है जिसमें Computer, Network, Internet या Digital Technology का उपयोग अपराध करने के लिए किया जाता है, या इन्हें निशाना बनाया जाता है।

उदाहरण

  • Online Banking Fraud.
  • Identity Theft.
  • Social Media Account Hacking.
  • Phishing.
  • Cyber Stalking.
  • Data Theft.
  • Online Financial Fraud.
🧠 Trick: Cyber Crime = Digital माध्यम से किया गया अपराध।
Topic 23

⚖️ भारत में IT Act 2000

Information Technology Act, 2000 भारत का प्रमुख कानून है जो Electronic Records, Digital Signatures और कुछ Cyber Crimes से संबंधित कानूनी प्रावधान प्रदान करता है।

महत्वपूर्ण धाराएँ

धाराविषय
Section 43बिना अनुमति Computer System को नुकसान पहुँचाने आदि पर क्षतिपूर्ति से संबंधित प्रावधान।
Section 65Computer Source Documents से छेड़छाड़।
Section 66Computer-related offences.
Section 66CIdentity Theft.
Section 66DComputer Resource के माध्यम से Personation द्वारा Cheating.
Section 66EPrivacy Violation.
Section 67Electronic Form में Obscene Material प्रकाशित या प्रसारित करना।
⭐ Exam Point: IT Act 2000 भारत में Electronic Transactions और Cyber Law का महत्वपूर्ण कानून है।
Topic 24

🏢 CERT-In क्या है?

CERT-In का पूरा नाम Indian Computer Emergency Response Team है। यह भारत की National Cyber Security Incident Response Agency है।

मुख्य कार्य

  • Cyber Security Incidents पर प्रतिक्रिया।
  • Security Alerts और Advisories जारी करना।
  • Cyber Security से संबंधित जानकारी साझा करना।
  • Cyber Incidents के समाधान में सहायता।
⭐ Important: CERT-In भारत के MeitY के अंतर्गत कार्य करता है।
Topic 25

📞 Cyber Fraud होने पर क्या करें?

यदि आपके साथ Online Financial Fraud होता है, तो तुरंत कार्रवाई करना महत्वपूर्ण है।

  • तुरंत 1930 Cyber Financial Fraud Helpline पर संपर्क करें।
  • National Cyber Crime Reporting Portal पर शिकायत दर्ज करें।
  • Bank को तुरंत सूचित करें और Account/Card को सुरक्षित करें।
  • Transaction ID, SMS और अन्य प्रमाण सुरक्षित रखें।
  • OTP, PIN और Password किसी से साझा न करें।

आधिकारिक पोर्टल: cybercrime.gov.in

Helpline: 1930

🎯 Exam Point: भारत में Cyber Financial Fraud की शिकायत के लिए Helpline Number 1930 है।

  • Cyber Security = Digital Systems की सुरक्षा।
  • CIA = Confidentiality, Integrity, Availability.
  • Malware = Malicious Software.

  • Worm = स्वयं की Copies बनाकर फैल सकता है।
  • Trojan = उपयोगी Software जैसा दिखने वाला Malware.
  • Ransomware = Data Lock या Encrypt करके फिरौती माँगना।
  • Spyware = गुप्त रूप से जानकारी एकत्र करना।
  • Keylogger = Keyboard Activity Record करना।
  • Phishing = नकली पहचान से जानकारी चुराने का प्रयास।
  • Smishing = SMS आधारित Phishing.
  • Vishing = Voice या Call आधारित Phishing.
  • DDoS = कई स्रोतों से Denial of Service Attack.
  • Firewall = Network Traffic नियंत्रित करना।
  • Antivirus = Malware Detection और Removal.
  • VPN = Virtual Private Network.
  • 2FA = Two-Factor Authentication.
  • Encryption = Data को Coded Form में बदलना।
  • Decryption = Coded Data को वापस पढ़ना।
  • IT Act = Information Technology Act, 2000.
  • CERT-In = Indian Computer Emergency Response Team.
  • 1930 = Cyber Financial Fraud Helpline.
