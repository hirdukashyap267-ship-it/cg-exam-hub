DBMS Complete Notes in Hindi

Database Management System के सभी महत्वपूर्ण टॉपिक आसान हिंदी भाषा में। परीक्षा के लिए उपयोगी परिभाषाएँ, उदाहरण, Tricks और Important Facts।

25 Important Topics Exam Special Notes
Topic 01

📘 DBMS क्या है?

DBMS का पूरा नाम: Database Management System.

DBMS एक Software है जिसकी सहायता से Database को बनाया, व्यवस्थित, सुरक्षित और नियंत्रित किया जाता है।

DBMS के मुख्य कार्य

  • Data को Store करना।
  • Data को Insert, Update और Delete करना।
  • Data को Search और Retrieve करना।
  • Data की Security बनाए रखना।
  • Data का Backup और Recovery करना।
🧠 याद रखने की Trick: DBMS = Data को Manage करने वाला Software.
🎯 Exam Point: DBMS का पूरा नाम Database Management System है।
Topic 02

🗄️ Database क्या है?

Database संबंधित Data का व्यवस्थित संग्रह होता है, जिसे आसानी से Access, Manage और Update किया जा सकता है।

उदाहरण

  • School का Student Record.
  • Bank का Customer Account.
  • Hospital का Patient Record.
  • Online Shopping का Product Record.
🧠 Trick: Database = संबंधित Data का संग्रह।
Topic 03

📂 DBMS के प्रकार

  1. Hierarchical DBMS: Data Tree Structure में व्यवस्थित होता है।
  2. Network DBMS: Data आपस में Network की तरह जुड़ा होता है।
  3. Relational DBMS: Data Tables के रूप में रखा जाता है।
  4. Object-Oriented DBMS: Data Objects के रूप में व्यवस्थित होता है।
⭐ Important Fact: RDBMS में Data Rows और Columns वाली Tables में Store होता है।
Topic 04

🔗 RDBMS क्या है?

RDBMS का पूरा नाम Relational Database Management System है। इसमें Data को Tables में Store किया जाता है और Tables के बीच Relationship बनाया जा सकता है।

उदाहरण

  • MySQL
  • Oracle Database
  • Microsoft SQL Server
  • PostgreSQL
  • SQLite
🧠 Trick: RDBMS = Relation + Tables.
Topic 05

📊 Table, Row और Column

Table: Data को Rows और Columns में रखने की संरचना।

Row: एक पूरा Record या Tuple.

Column: किसी एक प्रकार की जानकारी या Attribute.

Roll No.NameClass
101Rahul12th
102Amit11th
103Ravi12th
⭐ Important: Row = Record, Column = Field या Attribute.
Topic 06

🔑 Database Keys

Keys का उपयोग Table में Records की पहचान करने और Tables के बीच संबंध बनाने के लिए किया जाता है।

  • Primary Key: प्रत्येक Record की Unique पहचान करती है। इसमें Duplicate और NULL Value नहीं होती।
  • Foreign Key: दूसरी Table की Primary Key को Reference करती है।
  • Candidate Key: वह Column या Columns जो Primary Key बनने योग्य हों।
  • Alternate Key: Candidate Keys में से Primary Key के रूप में चुनी नहीं गई Key.
  • Composite Key: दो या अधिक Columns से मिलकर बनी Key.
  • Super Key: वह Attribute या Attributes का समूह जो Record को Uniquely पहचान सके।
  • Unique Key: Column में Unique Values सुनिश्चित करती है; NULL की अनुमति DBMS के अनुसार अलग हो सकती है।
🧠 Trick: Primary = मुख्य पहचान, Foreign = दूसरी Table से संबंध।
🎯 Exam Point: Primary Key में Duplicate और NULL Value स्वीकार नहीं होती।
Topic 07

🧩 Entity और Attribute

Entity: वास्तविक दुनिया की कोई वस्तु या व्यक्ति जिसके बारे में Data Store किया जाता है।

उदाहरण: Student, Teacher, Book, Employee.

Attribute: Entity की विशेषता को Attribute कहते हैं।

उदाहरण: Student की Roll Number, Name, Age.

🧠 Trick: Entity = वस्तु, Attribute = उसकी विशेषता।
Topic 08

🔄 Relationship के प्रकार

  • One-to-One (1:1): एक Record का संबंध दूसरे Table के एक Record से।
  • One-to-Many (1:M): एक Record का संबंध कई Records से।
  • Many-to-Many (M:N): कई Records का संबंध कई Records से।
⭐ उदाहरण: एक Department में कई Employees हो सकते हैं — One-to-Many.
Topic 09

🖼️ ER Model

ER का पूरा नाम Entity Relationship है। ER Model Database की संरचना को चित्र के माध्यम से दर्शाता है।

  • Entity को Rectangle से दिखाते हैं।
  • Attribute को Oval से दिखाते हैं।
  • Relationship को Diamond से दिखाते हैं।
  • Primary Key Attribute को अक्सर Underline किया जाता है।
🧠 Trick: Rectangle = Entity, Oval = Attribute, Diamond = Relationship.
Topic 10

📝 SQL क्या है?

SQL का पूरा नाम Structured Query Language है। इसका उपयोग Relational Database में Data को Create, Retrieve, Update और Delete करने के लिए किया जाता है।

SQL के प्रमुख उपयोग

  • Database बनाना।
  • Table बनाना।
  • Data Insert करना।
  • Data Search करना।
  • Data Update और Delete करना।
⭐ Exam Point: SQL का पूरा नाम Structured Query Language है।
Topic 11

📚 SQL Commands के प्रकार

प्रकारपूरा नामउदाहरण
DDLData Definition LanguageCREATE, ALTER, DROP, TRUNCATE
DMLData Manipulation LanguageINSERT, UPDATE, DELETE
DQLData Query LanguageSELECT
DCLData Control LanguageGRANT, REVOKE
TCLTransaction Control LanguageCOMMIT, ROLLBACK, SAVEPOINT
🧠 Trick: DDL = Structure, DML = Data, DQL = Query, DCL = Permission, TCL = Transaction.
Topic 12

🏗️ DDL Commands

  • CREATE: Database या Table बनाने के लिए।
  • ALTER: Table की Structure बदलने के लिए।
  • DROP: Database Object को हटाने के लिए।
  • TRUNCATE: Table के सभी Records हटाने के लिए, Structure बना रहता है।
🎯 Exam Point: CREATE, ALTER, DROP और TRUNCATE DDL Commands हैं।
Topic 13

✍️ DML Commands

  • INSERT: नया Record जोड़ना।
  • UPDATE: मौजूदा Record में बदलाव करना।
  • DELETE: Record हटाना।

उदाहरण

INSERT INTO Student
VALUES (101, 'Rahul');

UPDATE Student
SET Name = 'Amit'
WHERE RollNo = 101;

DELETE FROM Student
WHERE RollNo = 101;
🧠 Trick: INSERT = जोड़ना, UPDATE = बदलना, DELETE = हटाना।
Topic 14

🔍 SELECT Command

SELECT Command का उपयोग Table से Data प्राप्त करने के लिए किया जाता है।

SELECT * FROM Student;

SELECT Name FROM Student;

SELECT * FROM Student
WHERE Class = '12th';
  • SELECT: Data प्राप्त करना।
  • FROM: Table का नाम बताना।
  • WHERE: Condition लगाना।
  • ORDER BY: Data को क्रम में दिखाना।
  • GROUP BY: समान Values के आधार पर Group बनाना।
  • HAVING: Groups पर Condition लगाना।
⭐ Important: SELECT * का अर्थ Table के सभी Columns को प्राप्त करना है।
Topic 15

⚖️ SQL Operators

  • Arithmetic: +, -, *, /, %
  • Comparison: =, !=, , =, =
  • Logical: AND, OR, NOT
  • Special: BETWEEN, IN, LIKE, IS NULL

उदाहरण

SELECT * FROM Student
WHERE Marks > 60 AND Class = '12th';
🧠 Trick: AND में सभी Conditions सही, OR में कम-से-कम एक Condition सही।
Topic 16

🔗 SQL Joins

Join का उपयोग दो या अधिक Tables के संबंधित Records को जोड़कर Data प्राप्त करने के लिए किया जाता है।

  • INNER JOIN: दोनों Tables में Match होने वाले Records।
  • LEFT JOIN: Left Table के सभी Records और Right Table के Matching Records।
  • RIGHT JOIN: Right Table के सभी Records और Left Table के Matching Records।
  • FULL OUTER JOIN: दोनों Tables के सभी Records; Match न होने पर दूसरी तरफ NULL।
  • CROSS JOIN: दोनों Tables के Records का Cartesian Product.
  • SELF JOIN: किसी Table को उसी Table के साथ Join करना।
🧠 Trick: INNER = Matching, LEFT = Left के सभी, RIGHT = Right के सभी।
Topic 17

📐 Normalization

Normalization Database में Data को व्यवस्थित करने की प्रक्रिया है। इसका उद्देश्य Data Redundancy कम करना और Data Anomalies से बचना है।

  • 1NF: प्रत्येक Cell में Atomic यानी एक ही Value होनी चाहिए।
  • 2NF: 1NF में हो और प्रत्येक Non-key Attribute पूरी Candidate Key पर निर्भर हो।
  • 3NF: 2NF में हो और Non-key Attributes में Transitive Dependency न हो।
  • BCNF: हर Non-trivial Functional Dependency में Determinant Super Key होना चाहिए।
🧠 Trick: 1NF = Atomic, 2NF = Full Dependency, 3NF = No Transitive Dependency.
Topic 18

🔐 ACID Properties

ACID Properties Database Transaction को विश्वसनीय बनाने के लिए उपयोग होती हैं।

  • Atomicity: Transaction पूरा होगा या बिल्कुल नहीं होगा।
  • Consistency: Transaction के बाद Database Valid State में रहेगा।
  • Isolation: Concurrent Transactions एक-दूसरे के बीच अनुचित हस्तक्षेप नहीं करेंगी।
  • Durability: Commit होने के बाद बदलाव सुरक्षित रहते हैं।
🧠 Trick: A = All or Nothing, C = Correct State, I = Independent, D = Data Permanent.
🎯 Exam Point: ACID का संबंध Database Transactions से है।
Topic 19

🔄 Transaction क्या है?

Transaction Database पर किए जाने वाले एक या अधिक Operations का ऐसा समूह है जिसे एक Logical Unit की तरह माना जाता है।

Transaction Commands

  • COMMIT: बदलाव स्थायी रूप से Save करना।
  • ROLLBACK: Commit से पहले किए गए बदलाव वापस लेना।
  • SAVEPOINT: Transaction में एक Point बनाना जहाँ तक Rollback किया जा सकता है।
🧠 Trick: COMMIT = Save, ROLLBACK = वापस।
Topic 20

🛡️ Database Security

Database Security का उद्देश्य Data को Unauthorized Access, चोरी, बदलाव और नुकसान से सुरक्षित रखना है।

  • Authentication: User की पहचान की जाँच।
  • Authorization: User को अनुमति देना।
  • Encryption: Data को सुरक्षित रूप में बदलना।
  • Backup: Data की अतिरिक्त Copy रखना।
  • Audit: Database Activities का Record रखना।
⭐ Important: Authentication = आप कौन हैं? Authorization = आपको क्या करने की अनुमति है?
Topic 21

💾 Database Backup और Recovery

Backup: Database की अतिरिक्त Copy बनाना।

Recovery: खराबी या Data Loss के बाद Database को फिर से उपयोग योग्य स्थिति में लाना।

  • Full Backup: पूरे Database की Copy.
  • Incremental Backup: पिछले Backup के बाद हुए बदलावों की Copy.
  • Differential Backup: अंतिम Full Backup के बाद हुए बदलावों की Copy.
🧠 Trick: Backup = सुरक्षित Copy, Recovery = वापस प्राप्त करना।
Topic 22

🧠 Data Redundancy और Integrity

Data Redundancy: एक ही Data का अनावश्यक रूप से कई स्थानों पर दोहराया जाना।

Data Integrity: Data की Accuracy, Consistency और Reliability बनाए रखना।

Integrity Constraints

  • Entity Integrity: Primary Key NULL नहीं हो सकती।
  • Referential Integrity: Foreign Key का Reference सही होना चाहिए, या NULL हो सकती है जहाँ अनुमति हो।
  • Domain Integrity: Column में निर्धारित प्रकार और सीमा के अनुसार Value हो।
  • Key Constraint: Key की Uniqueness बनाए रखना।
⭐ Exam Point: Normalization का एक प्रमुख उद्देश्य Data Redundancy को कम करना है।
Topic 23

⚙️ Indexing क्या है?

Indexing Database में Data को तेजी से Search करने में सहायता करती है। Index एक अतिरिक्त Data Structure होता है जो Records को जल्दी खोजने में मदद करता है।

  • Primary Index
  • Secondary Index
  • Clustered Index
  • Non-Clustered Index
🧠 Trick: Index = किताब की विषय सूची की तरह, जिससे जानकारी जल्दी मिलती है।
🎯 Exam Point: Index Search को तेज कर सकता है, लेकिन अतिरिक्त Storage लेता है और Data Modification पर Maintenance की जरूरत होती है।
Topic 24

👨‍💻 SQL Constraints

Constraints का उपयोग Table में Data पर नियम लागू करने के लिए किया जाता है।

  • NOT NULL: NULL Value को रोकता है।
  • UNIQUE: Duplicate Values को रोकता है।
  • PRIMARY KEY: Record की Unique पहचान।
  • FOREIGN KEY: दूसरे Table से संबंध।
  • CHECK: Condition के अनुसार Value स्वीकार करना।
  • DEFAULT: Value न देने पर Default Value लगाना।
🧠 Trick: Constraints = Data पर नियम।
