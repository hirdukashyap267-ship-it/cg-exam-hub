MS Word Introduction

1. MS Word क्या है?

MS Word का पूरा नाम Microsoft Word है। यह Microsoft कंपनी द्वारा विकसित एक Word Processing Software है। इसका उपयोग पत्र, आवेदन, रिपोर्ट, रिज्यूमे, नोट्स और अन्य दस्तावेज बनाने के लिए किया जाता है।

MS Word में हम टेक्स्ट टाइप कर सकते हैं, फॉन्ट बदल सकते हैं, चित्र लगा सकते हैं, टेबल बना सकते हैं और दस्तावेज को प्रिंट या PDF के रूप में सेव कर सकते हैं। यह Microsoft Office और Microsoft 365 के अंतर्गत उपलब्ध है।

🧠 याद रखने की Trick: MS Word = Document बनाने और Edit करने का सॉफ्टवेयर।
⭐ Important Facts: MS Word एक Word Processing Software है।
🎯 Exam Point: MS Word का उपयोग दस्तावेज बनाने, संपादित करने और प्रिंट करने में होता है।
History

2. MS Word का इतिहास

Microsoft Word को शुरुआत में Multi-Tool Word के नाम से विकसित किया गया था। इसे Microsoft के लिए Richard Brodie ने विकसित किया था। इसका पहला संस्करण 1983 में जारी हुआ था।

समय के साथ MS Word में अनेक सुविधाएँ जोड़ी गईं। आज इसमें टेक्स्ट फॉर्मेटिंग, टेबल, चित्र, स्पेलिंग जाँच, Mail Merge, PDF Export और सहयोग से दस्तावेज संपादन जैसी सुविधाएँ उपलब्ध हैं।

🧠 याद रखने की Trick: Word का पहला संस्करण — 1983।
⭐ Important Facts: MS Word का विकास Microsoft ने किया।
🎯 Exam Point: MS Word के विकास से जुड़े प्रमुख नाम Richard Brodie हैं।
MS Word Interface

3. MS Word की स्क्रीन के मुख्य भाग

जब हम MS Word खोलते हैं, तो स्क्रीन पर कई भाग दिखाई देते हैं। सबसे ऊपर Title Bar होती है, जिसमें दस्तावेज का नाम दिखाई देता है। Quick Access Toolbar में Save, Undo और Redo जैसे विकल्प मिलते हैं।

Ribbon में अलग-अलग Tabs और Groups होते हैं। Document Area वह स्थान है जहाँ हम लिखते और संपादन करते हैं। Status Bar में पेज संख्या और शब्दों की संख्या जैसी जानकारी दिखाई देती है।

🧠 याद रखने की Trick: Title Bar = नाम, Ribbon = Tools, Document Area = लिखने की जगह।
⭐ Important Facts: Ribbon में Tabs, Groups और Commands होते हैं।
🎯 Exam Point: Status Bar में पेज और शब्दों की जानकारी देखी जा सकती है।
File Tab

4. File Tab के महत्वपूर्ण विकल्प

File Tab में दस्तावेज से जुड़े मुख्य कार्य होते हैं। New से नया दस्तावेज बनाया जाता है, Open से पहले से सेव फाइल खोली जाती है और Save से वर्तमान फाइल सेव की जाती है।

Save As से दस्तावेज को नए नाम, स्थान या फॉर्मेट में सेव किया जा सकता है। Print से दस्तावेज प्रिंट किया जाता है। Export विकल्प से PDF जैसे दूसरे फॉर्मेट में फाइल बनाई जा सकती है।

🧠 याद रखने की Trick: New = नया, Open = खोलना, Save = सुरक्षित करना, Print = छापना।
⭐ Important Facts: Save As से फाइल का नाम या स्थान बदलकर सेव किया जा सकता है।
🎯 Exam Point: Print Preview से प्रिंट से पहले दस्तावेज का रूप देखा जा सकता है।
Home Tab

5. Home Tab क्या है?

Home Tab MS Word का सबसे अधिक उपयोग होने वाला Tab है। इसमें Clipboard, Font, Paragraph, Styles और Editing जैसे Groups होते हैं। इनकी सहायता से टेक्स्ट कॉपी, पेस्ट, फॉर्मेट और व्यवस्थित किया जाता है।

Home Tab से हम अक्षरों का आकार, रंग, मोटाई, पैराग्राफ का संरेखण और लाइन स्पेसिंग बदल सकते हैं। इसमें Find और Replace जैसे विकल्प भी उपलब्ध होते हैं।

🧠 याद रखने की Trick: Home Tab = Text Editing और Formatting।
⭐ Important Facts: Home Tab में Font और Paragraph Groups मिलते हैं।
🎯 Exam Point: Bold, Italic और Underline विकल्प Font Group में होते हैं।
Font Group

6. Font Group के विकल्प

Font Group का उपयोग अक्षरों और शब्दों का रूप बदलने के लिए किया जाता है। Font Name से अक्षरों की शैली और Font Size से अक्षरों का आकार बदला जाता है। Font Color से अक्षरों का रंग बदला जा सकता है।

Bold से अक्षर मोटे, Italic से तिरछे और Underline से अक्षरों के नीचे रेखा लगाई जाती है। Strikethrough से टेक्स्ट के बीच में रेखा दिखाई जाती है। Superscript और Subscript का उपयोग छोटे ऊपरी और निचले अक्षर लिखने में होता है।

🧠 याद रखने की Trick: B = Bold, I = Italic, U = Underline।
⭐ Important Facts: Font Size सामान्यतः Point (pt) में मापी जाती है।
🎯 Exam Point: Ctrl + B = Bold, Ctrl + I = Italic, Ctrl + U = Underline।
Paragraph Group

7. Paragraph Group

Paragraph Group का उपयोग टेक्स्ट को सही ढंग से व्यवस्थित करने के लिए किया जाता है। इसमें Alignment, Bullets, Numbering, Indentation, Line Spacing और Borders जैसे विकल्प होते हैं।

Alignment के चार प्रमुख प्रकार हैं — Left, Center, Right और Justify। Justify में टेक्स्ट दोनों किनारों से व्यवस्थित दिखाई देता है। Bullets से बिंदुओं की सूची और Numbering से क्रमांक वाली सूची बनाई जाती है।

🧠 याद रखने की Trick: Left = बायाँ, Center = बीच, Right = दायाँ, Justify = दोनों किनारे।
⭐ Important Facts: Ctrl + L = Left, Ctrl + E = Center, Ctrl + R = Right, Ctrl + J = Justify।
🎯 Exam Point: Bullets और Numbering का उपयोग सूची बनाने के लिए होता है।
Styles

8. Styles एवं Editing

Styles का उपयोग दस्तावेज में Heading, Title और अन्य टेक्स्ट को एक समान रूप देने के लिए किया जाता है। इससे बड़े दस्तावेज को व्यवस्थित करना आसान होता है। Heading Styles का उपयोग Table of Contents बनाने में भी मदद करता है।

Editing Group में Find, Replace और Select जैसे विकल्प होते हैं। Find से किसी शब्द को खोजा जाता है और Replace से एक शब्द को दूसरे शब्द से बदला जा सकता है।

🧠 याद रखने की Trick: Find = खोजना, Replace = बदलना, Select = चुनना।
⭐ Important Facts: Ctrl + H = Replace, Ctrl + F = Find।
🎯 Exam Point: Styles से दस्तावेज की Heading और Formatting एक समान रखी जा सकती है।
Insert Tab

9. Insert Tab के महत्वपूर्ण विकल्प

Insert Tab का उपयोग दस्तावेज में नई चीजें जोड़ने के लिए किया जाता है। इसमें Pages, Table, Pictures, Shapes, Icons, SmartArt, Chart, Header, Footer, Page Number और Text Box जैसे विकल्प होते हैं।

उदाहरण के लिए किसी रिपोर्ट में चित्र लगाना हो, तालिका बनानी हो या पेज नंबर जोड़ना हो, तो Insert Tab का उपयोग किया जाता है।

🧠 याद रखने की Trick: Insert = दस्तावेज में नई सामग्री जोड़ना।
⭐ Important Facts: Table, Pictures और Page Number Insert Tab में मिलते हैं।
🎯 Exam Point: पेज नंबर जोड़ने के लिए Insert Tab का उपयोग किया जाता है।
Table

10. MS Word में Table बनाना

Table का उपयोग डेटा को Rows और Columns में व्यवस्थित करने के लिए किया जाता है। उदाहरण के लिए विद्यार्थियों के नाम, रोल नंबर और अंक को एक तालिका में दिखाया जा सकता है।

Insert Tab के Table विकल्प से आवश्यक Rows और Columns चुनकर टेबल बनाई जा सकती है। टेबल में नई Row या Column जोड़ना, हटाना, Cell Merge करना और डिजाइन बदलना संभव है।

🧠 याद रखने की Trick: Row = पंक्ति, Column = स्तंभ, Cell = खाना।
⭐ Important Facts: Row और Column के मिलने से Cell बनता है।
🎯 Exam Point: टेबल का उपयोग डेटा को व्यवस्थित रूप में दिखाने के लिए किया जाता है।
Pictures & Shapes

11. Pictures, Shapes और SmartArt

MS Word में Insert Tab की सहायता से दस्तावेज में चित्र, आकृतियाँ और SmartArt जोड़े जा सकते हैं। Pictures से फोटो लगाई जाती है, Shapes से तीर, वृत्त और अन्य आकृतियाँ बनाई जाती हैं।

SmartArt का उपयोग प्रक्रिया, संबंध, संगठन संरचना और अन्य जानकारियों को चित्रात्मक रूप में दिखाने के लिए किया जाता है। Chart से डेटा का ग्राफ तैयार किया जा सकता है।

🧠 याद रखने की Trick: Picture = फोटो, Shapes = आकृतियाँ, SmartArt = जानकारी का चित्रात्मक प्रदर्शन।
⭐ Important Facts: Chart डेटा को ग्राफ के रूप में दिखाता है।
🎯 Exam Point: SmartArt का उपयोग जानकारी को दृश्य रूप में प्रस्तुत करने के लिए होता है।
Header & Footer

12. Header, Footer और Page Number

Header पेज के ऊपरी हिस्से में दिखाई देता है, जबकि Footer पेज के निचले हिस्से में दिखाई देता है। इनका उपयोग दस्तावेज का नाम, अध्याय, तारीख या अन्य जानकारी हर पेज पर दिखाने के लिए किया जाता है।

Page Number से दस्तावेज के पेजों पर क्रमांक लगाए जाते हैं। इससे बड़े दस्तावेज को पढ़ना और व्यवस्थित रखना आसान हो जाता है।

🧠 याद रखने की Trick: Header = ऊपर, Footer = नीचे।
⭐ Important Facts: Header और Footer Insert Tab में उपलब्ध होते हैं।
🎯 Exam Point: पेज नंबर जोड़ने के लिए Insert → Page Number का उपयोग होता है।
Layout Tab

13. Layout Tab

Layout Tab का उपयोग पेज की बनावट और टेक्स्ट की स्थिति बदलने के लिए किया जाता है। इसमें Margins, Orientation, Size, Columns, Breaks, Indent और Spacing जैसे विकल्प मिलते हैं।

Orientation के दो प्रमुख प्रकार हैं — Portrait और Landscape। Portrait में पेज लंबवत होता है, जबकि Landscape में पेज आड़ा होता है। Margins से पेज के चारों ओर खाली जगह निर्धारित की जाती है।

🧠 याद रखने की Trick: Portrait = लंबवत, Landscape = आड़ा।
⭐ Important Facts: Page Orientation के दो प्रमुख विकल्प Portrait और Landscape हैं।
🎯 Exam Point: पेज का आकार बदलने के लिए Layout → Size का उपयोग किया जाता है।
References Tab

14. References Tab

References Tab का उपयोग बड़े दस्तावेज, रिपोर्ट और शोध कार्य में संदर्भ जोड़ने के लिए किया जाता है। इसमें Table of Contents, Footnotes, Citations, Bibliography, Captions और Index जैसे विकल्प मिलते हैं।

Table of Contents से दस्तावेज के अध्यायों और शीर्षकों की सूची बनाई जा सकती है। Footnote पेज के नीचे अतिरिक्त जानकारी देता है। Citation किसी स्रोत का उल्लेख करने के लिए उपयोग होता है।

🧠 याद रखने की Trick: References = विषय सूची और स्रोतों की जानकारी।
⭐ Important Facts: Table of Contents बनाने के लिए Heading Styles का सही उपयोग महत्वपूर्ण है।
🎯 Exam Point: Footnote पेज के निचले हिस्से में अतिरिक्त जानकारी देता है।
Mail Merge

15. Mail Merge क्या है?

Mail Merge MS Word की एक महत्वपूर्ण सुविधा है। इसका उपयोग एक ही प्रकार के पत्र, निमंत्रण या प्रमाणपत्र को कई अलग-अलग लोगों के नाम और पते के साथ तैयार करने के लिए किया जाता है।

Mail Merge में मुख्य रूप से Main Document, Data Source और Merge Fields का उपयोग होता है। Main Document में सामान्य सामग्री होती है, Data Source में लोगों के नाम और पते जैसे रिकॉर्ड होते हैं और Merge Fields से इन रिकॉर्डों को दस्तावेज में जोड़ा जाता है।

🧠 याद रखने की Trick: एक पत्र + कई लोगों का डेटा = Mail Merge।
⭐ Important Facts: Mail Merge का उपयोग व्यक्तिगत पत्रों और लेबल बनाने में किया जा सकता है।
🎯 Exam Point: Mail Merge में Main Document और Data Source महत्वपूर्ण भाग हैं।
Review Tab

16. Review Tab

Review Tab का उपयोग दस्तावेज की जाँच और समीक्षा करने के लिए किया जाता है। इसमें Spelling & Grammar, Thesaurus, Word Count, Translate, Comments और Track Changes जैसे विकल्प मिलते हैं।

Track Changes की मदद से दस्तावेज में किए गए बदलावों को देखा और स्वीकार या अस्वीकार किया जा सकता है। Comments से किसी हिस्से के बारे में टिप्पणी लिखी जा सकती है।

🧠 याद रखने की Trick: Review = जाँच और सुधार।
⭐ Important Facts: Track Changes दस्तावेज में किए गए बदलावों को ट्रैक करता है।
🎯 Exam Point: Spelling और Grammar जाँचने के लिए Review Tab का उपयोग किया जाता है।
View Tab

17. View Tab

View Tab का उपयोग दस्तावेज को अलग-अलग तरीकों से देखने के लिए किया जाता है। इसमें Read Mode, Print Layout, Web Layout, Navigation Pane, Zoom और Ruler जैसे विकल्प मिलते हैं।

Print Layout में दस्तावेज वैसा दिखाई देता है जैसा सामान्यतः प्रिंट में दिखेगा। Zoom से पेज को बड़ा या छोटा करके देखा जा सकता है। Ruler से टेक्स्ट और पैराग्राफ की स्थिति व्यवस्थित करने में मदद मिलती है।

🧠 याद रखने की Trick: View = दस्तावेज देखने का तरीका।
⭐ Important Facts: Zoom से दस्तावेज को बड़ा या छोटा करके देखा जाता है।
🎯 Exam Point: Print Layout दस्तावेज का प्रिंट जैसा दृश्य दिखाता है।
Save & Print

18. दस्तावेज Save और Print करना

दस्तावेज तैयार करने के बाद उसे सुरक्षित रखना जरूरी होता है। Save विकल्प से फाइल को कंप्यूटर में सेव किया जाता है। पहली बार सेव करते समय फाइल का नाम और स्थान चुनना पड़ता है।

Print विकल्प से दस्तावेज कागज पर छापा जा सकता है। Print से पहले प्रिंटर, पेज रेंज, कॉपी की संख्या और पेज सेटिंग चुनी जा सकती है। PDF के रूप में सेव करने से दस्तावेज को आसानी से साझा किया जा सकता है।

🧠 याद रखने की Trick: Ctrl + S = Save, Ctrl + P = Print।
⭐ Important Facts: PDF का पूरा नाम Portable Document Format है।
🎯 Exam Point: Save As से दस्तावेज को दूसरे नाम या फॉर्मेट में सेव किया जा सकता है।
